개인정보처리방침 — Sip Note

최종 수정일: 2026-08-15

요약

Sip Note 는 사용자의 어떤 데이터도 수집하거나 외부로 전송하지 않습니다. 계정도 서버도 없습니다. 앱에 남긴 모든 기록은 사용자의 기기 안에만 저장됩니다.

1. 기기에 저장되는 정보

앱은 다음을 기기 내부 데이터베이스(SQLite)와 앱 전용 저장 공간에 보관합니다.

항목내용
테이스팅 기록주류 이름, 카테고리, 점수, 태그, 메모, 가격, 날짜
사진사용자가 촬영하거나 선택한 사진의 압축 복사본
장소장소 이름, 주소, 좌표, 도시/지역, 방문 횟수, 위시리스트 여부
페어링음식 이름, 궁합 점수, 메모, 사진
앱 설정알림 on/off 와 시각, 테마, 통화, 뱃지 진행도

이 정보는 개발자를 포함한 누구에게도 전송되지 않습니다.

2. 기기 권한

권한사용 목적거부하면
카메라기록에 붙일 사진 촬영촬영 대신 갤러리 선택만 사용
사진 / 미디어갤러리에서 사진 선택사진 없이 기록 작성
위치 (사용 중)장소를 만들 때 현재 위치와 도시명 확인장소를 직접 입력
알림기록 리마인더, 주간 리포트알림만 오지 않음

모든 권한은 거부해도 앱의 나머지 기능이 정상 동작합니다.

3. 위치 정보

  • 좌표는 장소 기록에만 쓰이며 기기를 떠나지 않습니다.
  • 도시/지역 이름은 운영체제의 지오코딩 기능으로 좌표를 변환해 얻습니다. 이 변환은 Apple / Google 의 기기·플랫폼 서비스가 수행하며, 각 플랫폼의 개인정보처리방침이 적용됩니다.
  • 앱을 사용 중일 때만 위치를 확인하며, 백그라운드에서 위치를 수집하지 않습니다.

4. 지도

지도 화면은 Google Maps SDK 로 지도 타일을 불러옵니다. 이때 지도를 그리기 위한 요청이 Google 에 전달되며, 사용자의 기록·사진·메모는 전송되지 않습니다. Google 의 처리에 대해서는 Google 개인정보처리방침을 따릅니다.

5. 광고 · 분석

광고 SDK, 분석 SDK, 크래시 리포팅을 포함하지 않습니다.

6. 데이터 내보내기와 삭제

  • 내보내기: 사용자가 직접 실행할 때만 JSON / CSV / zip 파일을 만들고, 운영체제의 공유 기능으로 사용자가 고른 곳에만 전달됩니다.
  • 삭제: 설정 > 데이터 초기화에서 모든 기록·사진·뱃지·설정을 영구 삭제할 수 있습니다. 앱을 삭제해도 기기 안의 데이터는 함께 사라집니다.
  • 서버에 사본이 없으므로 앱 삭제 후에는 복구할 수 없습니다. 필요하면 먼저 내보내기로 백업하세요.

7. 아동

만 18세 미만 사용자를 대상으로 하지 않습니다.

8. 변경

방침이 바뀌면 이 문서의 최종 수정일을 갱신하고 앱 업데이트 시 안내합니다.
